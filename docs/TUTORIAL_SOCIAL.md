## LinkedIn

A compute trade can look attractive on a chart and disappear once you account for execution costs.

We wrote a hands-on Compute Pulse tutorial for quant traders: collect Bitget and Lighter observations, run the repo's synthetic compute/energy paper strategy, then examine how size changes execution costs.

These are separate research exercises. The collector does not feed a live strategy, and the Hummingbot adapter records quotes without placing orders. Architect's authenticated data path is documented separately.

The code is public and contributions are welcome, especially connector testing, funding normalization and historical data collection.
